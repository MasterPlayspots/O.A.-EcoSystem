# Public primary sources

Platform documentation retrieved on 12 October 2026. For software/hardware sources see also [Credits](../CREDITS.md).

**S01 — [GitHub CLI: create a repository](https://cli.github.com/manual/gh_repo_create)**. Syntax of --public, --source, --remote, --push; read on 12 Oct 2026.

**S02 — [GitHub CLI: configure a repository](https://cli.github.com/manual/gh_repo_edit)**. Issues, Discussions, wiki, default branch and merge options; check the current flags locally before running.

**S03 — [GitHub: rulesets](https://docs.github.com/en/repositories/configuring-branches-and-merges-in-your-repository/managing-rulesets/about-rulesets)**. Public repositories support rulesets; check the actual permissions separately.

**S04 — [GitHub: CODEOWNERS](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/about-code-owners)**. The file defines ownership; required reviews need platform rules.

**S05 — [GitHub: private vulnerability reporting](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/configure-vulnerability-reporting/configure-for-a-repository)**. Enable and verify a private reporting channel for a public repository.

**S06 — [GitHub Discussions](https://docs.github.com/en/discussions/quickstart)**. Categories, moderation and discussion structure.

**S07 — [GitHub Actions: secure use](https://docs.github.com/en/actions/reference/security/secure-use)**. Minimal permissions, pinned actions, no untrusted PRs on home runners.

**S08 — [Claude Code: project instructions](https://code.claude.com/docs/en/memory)**. CLAUDE.md with @AGENTS.md as the documented import approach.

**S09 — [GitHub CLI: check authentication](https://cli.github.com/manual/gh_auth_status)**. Do not use the --show-token option in the work request.

**S10 — [GitHub CLI: view a repository](https://cli.github.com/manual/gh_repo_view)**. Metadata/visibility check; not to be mistaken for an unauthenticated cross-check.

**S11 — [GitHub CLI: create an issue](https://cli.github.com/manual/gh_issue_create)**. Task files and actual URLs; deduplicate before creating.

**S12 — [GitHub CLI: create a discussion](https://cli.github.com/manual/gh_discussion_create)**. Check the version-dependent CLI availability; otherwise use the documented API/UI.

**S13 — [GitHub: licensing](https://docs.github.com/articles/licensing-a-repository)**. Public visibility and an open-source licence are separate properties.

**S14 — [GitHub: PR reviews](https://docs.github.com/en/pull-requests/reference/pull-request-reviews)**. Distinguish comments, approvals and required reviews.

These sources document platform functions and documented integrations, not their activation
in our own repository. Hardware/upstream statements from the credits register still require
versioned evidence for the respective device profile.
